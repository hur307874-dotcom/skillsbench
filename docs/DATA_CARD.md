## 体系防线（防线叙事用）
- 四关校验：首版 6 任务毙 4（死跑都能满分）→ 铁律"造卷不看答案，阅卷必须机器"
- 渠道协议：45 run 渠道死尸事件 → usage 二分（usage=0 基建失败 ≠ 能力失败）；熔断/串行补跑
- 天花板检测+决定性模式：sysdbg 冤案平反（"零增益"≠"测不出"）
- 污染探针：满分任务标识符扰动后仍满分 → 天花板=真能力非背题
- κ 门：归因器 v1 κ=0.152 自拦（门槛 0.7）；v2 前置活动性门回归 20/20（局限：同批卡自证）
