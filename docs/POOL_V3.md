# POOL_V3 设计：未知知识任务池（立项 2026-10-02，暂缓实施）

## 立项依据（三篇 2026 文献 + 自有数据四重印证）

| 证据 | 内容 | 对我们的意义 |
|---|---|---|
| SkillsBench（BenchFlow，84 任务 7308 trial） | Skill 平均 +16.2pp，增益集中在训练数据外知识（医疗 +51.9pp；洪水风险 2.9%→80%）；自写 Skill -1.3pp | Skill 价值在知识缺口处 |
| WebDev-Skills-Bench（百度 NLP，31×50×1000，四模型） | 注入平均有害（-1.3~-4.2pp），简单任务受害最重（-4~-10.7pp）；长度分心 vs 内容误导两失效；跨模型 r≤0.12 | 我们的 v1 成本+/零收益/弱基座失效 = 独立复现其有害区 |
| Agentic Skills 框架（alphaxiv） | Skill 改善"指令遵循"非"目标完成"；过程性 >> 抽象最佳实践 | tdd 属抽象最佳实践，null 是必然 |
| 自有数据（pool-v1/v2 全部批次） | 能力饱和任务上分数无区分、成本 +25~33% | 同左 |

## 设计原则

**任务必须让"必需知识/约定不在模型训练数据里"**：
A0 基线天然低（知识缺失）→ Skill 臂有赢的可能（H1 首次可能为正）
→ 测量对象 = Skills 声称的核心价值（过程知识注入）。

## 任务族（按可行性）

- **A. convention-forge（虚构约定库）**：杜撰语义的小包（自定义 Result 类型/
  命名规则/校验约定），约定只写在 Skill 里；隐藏测试判约定符合度。
  用 forge 引擎的"引擎/配方分离"直接生产（新配方 yaml + 新 Skill 对）。
- **B. 后 cutoff/冷门真库任务**：知识截止后发布或极冷门 PyPI 包 + 用法手册 Skill。
- **C. 过程序列任务**：多步过程，顺序/参数必须查文档（杜撰协议，洪水风险
  Log-Pearson 模式）。

## 配套臂扩展（WebDev 论文教训）

- **A0p 安慰剂臂**：长度匹配无关 Skill——分离"长度分心"与"内容误导"。
  （PLAN 早已设计，从未运行；pool-v3 必须带它，否则负收益无法归因。）

## 预期产出（两条路都是贡献）

- Skill 臂赢 → 边界精确定义："Skills 只在知识缺口处有用"；
- Skill 臂仍输 → "Skills 无用"证据链闭合（三篇文献 + 自有数据四层印证）。

## 状态：暂缓。前置 = 报告 v6.5 定稿 + A0p 臂落地（可先在 pool-v2 上跑）。

## 设计铁律（实战踩坑三条，2026-10-02）

- **v3.0 知识物理外置**：约定的命名/产物（哨兵类/校验函数）不得出现在
  fixture——v1 原型放进 fixture 被 A0 直接推断（天花板）。
- **v3.1 注释必须中性**：连"本包缺哨兵与校验设施"这类提示性注释都是
  泄题——强模型读完即推断出约定全貌（n=5 确认批 A0 1.00 翻车实证）。
- **v3.2 知识文档必须移出 agent 搜索半径**：评测 run 未隔离文件系统，
  agent 会搜遍工作区找"团队文档"（poolv3b A0 满分轨迹实证：find 全盘
  → 读到 skills/streamkit-convention/SKILL.md）。处置：知识文档移至
  工作区外随机路径（%TEMP%/skillbench-v3-skills-*），预设指向外迁路径。
  **终解 = docker 沙箱（文件系统隔离），恢复前 pool-v3 结论须标注
  "搜索半径缓解"前缀。**

## v3.4 正式版与 C7 判定（2026-10-04，docker 沙箱内全程）

### 新增铁律

- **v3.3 约定必须反直觉**：不能是行业通行做法（深拷贝/软删除/阶段顺序校验
  这类强模型读 prompt 就推断得出——poolv3c 时代 A0/安慰剂也能满分的根因之一）。
  v3.4 约定全部与常识反向（空输入返回 `BLANK` 哨兵而非空表、缺键返回 `ZILCH`
  而非抛异常、错误延迟到 flush 才抛等）。
- **v3.4 命名不可自然猜中**：`BLANK`/`BROKEN`/`ZILCH`/`_audit_inbound`/
  `SequenceFault`/`held`/`clobber`——模型无法从语义推断字面量。
- **v3.5 隔离由 docker 沙箱提供**（pi-docker 驱动）：agent 在容器内运行，
  只挂 /repo（fixture）与 /skill（注入臂）——搜盘泄题四通道物理关闭
  （冒烟实证：agent `find /` 全盘搜约定，容器内一无所获）。
  答案材料因此回归标准布局（tasks/<task>/tests 等），约定文档仍放
  D:/ai_project/skillbench-v3-secure/skills/ 作纵深防御。

## 总判定：**C7 成立（三族齐证，置信 ★★★）**

知识缺口任务上：A0 ≡ A0p（0.40~0.46——安慰剂与裸考无差，长度效应排除）
