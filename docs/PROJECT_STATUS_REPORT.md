## 3. 数据表现（核心发现）

### 3.1 收益维度：天花板，不可测 ⛔

所有模型在当前任务池上通过率 ~100%（quick-n3 全满分、glm 三代 A0 全过、b1-pilot 全过）。
**H1（Skill 有没有用）的收益侧在当前任务池上不可回答。** 唯一例外：glm-5.2 × A1f（见 3.3）。

### 3.2 成本维度：清晰且一致 ✅

| 信号 | 数据 | 出处 |
|---|---|---|
| A1f 注入后成本上升 | opus 线上 ×1.7–2.1（cache 创建） | real-q1 |
| A1f 轮次更多 | D3：A0 8.8 turns vs A1f 11.7 turns（**+33%**） | quick-n3 |
| A1f 墙钟更慢 | d3-cache：27s → 112s | pi-ql1 |

**tdd Skill 的"代价"维度在全模型全任务上一致为正——这是目前最稳的结论。**

### 3.3 行为维度：本轮王牌发现——I3 反噬 🔥

**glm-5.2 × A1f：6/10 通过（0.70），同模型 A0 全过（11/11）。**

失败 run 全部是真编辑真失败（非死跑），trace 显示 agent 严格遵循 tdd Skill 的
"先写复现测试（RED）"指令，**把全部预算耗在测试脚手架上，修复从未落地**
（最终陈述都停在"第一步 — RED"）。

- 这是 H1 机制性预测的首次真实验证：**流程纪律类指令（I3）在弱基座上收益为负**；
- 给消融实验提供了完美检验点：**A1-x3（去 I3）若恢复通过率，则 I3 是祸首**；
- 与成本维度互证（③ 环：Skill → 行为改变 → 成本上升/收益为负）。

### 3.4 行为信号检测器：校准后零命中（诚实阴性）

F15（幻影用户）检测器在 pi-ql1 上曾 5/5 全假阳（TDD 行话"RED confirmed"撞词），
收紧正则 + 6 回归单测后，quick-n3 零误报。其余 6 个检测器未经真实数据校准。

## 4. 产生的问题（按严重度）

### P0：任务池天花板（内容问题，未解决）

- 通过率维度全模型全任务满分 → 收益不可测；
- 三轮加料失败史：R1 全满分 → R2 双峰（0%/100%，无中间带）→ R3 又全满分；
- 根因：任务太小 + 判分约束反噬真实感 + 考生变强 + 难度是阶跃不是旋钮；
- **出路已定（任务池 v2）**：真实 commit 挖掘为主 + 放大合成为辅 + 部分分设计常态 +
  Pilot Gate 常驻入库门禁（40–80% 才准入）。

### P1：基建稳定性（已建立防线，需持续）

- **死跑现象**：并发 10 触发 relay 429 → pi 静默空完成（exit=0）；
  已对账：runner 死跑检测 + 断点续跑自动重试 + dis 并发上限 4；
- **glm-5.2 渠道不稳**：梯度批三轮续跑仍有 3 死跑（已排除统计）；
- **ENGINX 中转站死亡** → v6.5 全线切换 dis 线（已完成）。

### P2：方法论缺口

- 消融臂（A1-x1..x7）未跑——**当前最高优先级**，直接回答"I3 是不是祸首"；
- 归因器未建（F-ID 归因靠人工读 trace）；埋针校准未跑；A1 自主触发臂未跑；
- 其余 6 个行为信号检测器未校准。

### P3：产品外壳与合规

- 前端/API/docker 沙箱未建（题目要求容器隔离，现为临时目录代替）；
- 文档的 claude 中心叙述待改写为 harness 中立（v6.5 后）。

## 三、主线问题的答案（三批文献 + 自有数据四层印证）

**"Skills 有用吗"→"边界在哪"**：

1. **能力饱和任务上**（修 bug 类，训练数据里全是）：
   分数无正收益（四批 n=5）；v1 成本 +25~33%（四批复现）；
   v3 降本至 v1 与 A0 之间（四批复现）；
   v1 弱基座随机性预算失效；Skill 零产出税（弱基座 40% vs 裸考 5%）。
   ——与 WebDev-Skills-Bench（注入平均有害、简单任务受害最重）
   的有害区**独立复现级一致**。
2. **知识缺口任务上**（convention-forge）：
   **A0/A0p = 0.4，Skill 臂 = 0.9（n=3 全一致，+0.5）**——
   H1 首次为正，安慰剂臂证明非长度效应。
   ——与 SkillsBench（增益集中在训练外知识，洪水风险 2.9%→80%）
   的机制**精确同构**。
3. **边界初稿**：Skills 的价值 = 知识注入，只在"必需知识不在训练
   数据里"的任务上显现；在能力饱和处它是纯成本（+25~33% 轮次），
   在弱基座上还可能触发预算失效与零产出。
