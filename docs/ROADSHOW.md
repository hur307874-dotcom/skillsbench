# 路演最终版（研究重组版）：判分即立场
> 重组依据：评委 3 分钟定生死 → 强牌前置；只评"真做过/判断力/讲得清" → 每决策必落"我选了什么、为什么不选其他"；
> 预埋 3 个下钻点引评委进主场；超时=死刑（75% 设提醒）；演示预录备案；问答不复读文档。
> 总时长：15 分钟陈述 + 4 分钟演示 + Q&A。PPT ≤ 18 页（15×1.2）。

---

## 第 0 段 · 钩子（0:00–0:30）【三分钟法则：生死在这 30 秒】

"写一个 Skill 十分钟，判断它有没有用，行业靠'俺寻思'。我三周建了一套评测与优化体系，跑了 **119 个批次、近 2400 个可控实验**，回答出一句可证伪的判据——

> **Skill 要么递答案，要么收仪式税。界限只有一个：内容在不在模型的先验里。**

今天我不罗列功能，讲这台机器是怎么造出来的：先讲判分（分错全错），再讲它抓到的三个几乎写成错误结论的瞬间，最后讲它怎么从判分走到开处方。"

【设计意图：结论先行 + 两个硬数字（119/2400）证明"真做过"，30 秒内完成评委三件事的前两件】

## 第 1 段 · 机器：分是怎么判的（0:30–5:00）【真做过的证明】

**run 级判分（五步，每步一句依据一句哲学）**：

1. **一次性容器**：docker 只挂 /repo 和 /skill，tests 和答案物理不可达。
   依据：Inspect/Terminal-Bench 的沙箱标准形态 + 我们的事故（agent 曾 `find /` 读到答案）。
   哲学：**信任要用物理保证，不用纪律保证。**
2. **双臂注入**：A0 带 `--no-skills`，A1f 带 `--append-system-prompt`，机制保证"一个真没有、一个真注入"。
   依据：题目"加载与不加载"的消融底线。哲学：**干预存不存在，不能靠猜。**
3. **宿主机机械判分**：隐藏 pytest，f2p（修复必须过）× p2p（原功能不许挂），**全程零 LLM**。
   依据：SWE-bench 的 F2P/P2P 工业标准；MT-Bench 实测 LLM 判官四大偏差——**冗长偏差会定向偏爱输出更长的 Skill 臂**。
   哲学：**判分必须比被测对象更笨、更确定——造卷的不看答案，阅卷的必须是机器。**
4. **全事件留痕 + 环境快照**：trace.json 记录每个动作；驱动/模型/镜像 digest 随 run 落账。
   依据：题目"记录完整 Agent Loop 的 Trace"；二手渠道模型别名会漂移。
   哲学：**结论可以错，证据必须留；可复现不是口号，是数据 schema。**
5. **渠道死二分**：usage=0 的失败=基建失败剔除补跑，usage>0 的无编辑=合法结局。
   依据：45 个 run 的实战教训。哲学：**基建失败和能力失败混了，就是伪科学。**

**Skill 级流水线（六站）**：预检（渠道 down 熔断，不烧 run）→ 冒烟 6 run（**先验证仪器再相信读数**）→ 分诊 12 run（逐任务配对符号+成本比）→ 天花板检测（满分池上"出局"罪名不成立→决定性模式）→ 复测/确诊（**安慰剂臂**排除长度效应）→ 弊端定位→改进→再验证（题目核心闭环）。
（每站一句哲学，展开留 Q&A——**演示时只念站名和加粗句，细节等追问**。）

## 第 2 段 · 三个下钻点（5:00–10:00）【预埋主场：评委追问就掉进口袋】

### 下钻一：满分迷雾（现象→定位→方案→结果）
"第一版 6 任务三臂全满分，数据漂亮得能直接写'测不出增益'。我收手前多问一句：**会不会是题出坏了？** → 定位：给题目立四道机器生死门（gold 必过/错解必负/漏改必测/结构完整）→ 结果：**6 题毙 4 题——连一行代码没改的死跑都能拿满分**。赔偿：'造卷的不许看考生答案'成为体系第一铁律。"
【评委若追问"四关谁审"：全是机器可执行的否定性检查——是安检门不是选美】

### 下钻二：渠道混淆（45 个 run 的命）
"两批 45 个 run 全部零编辑零分，我差点报'注入后能力归零'。挖 trace：中转站降级——空响应、400、403。**能力结论其实是基建死尸。** → 方案：跑批前渠道探测熔断 + usage 二分 + 串行补跑 + 每条结论强制披露渠道健康。→ 从此基建噪声再也没混进过能力结论。"
【这是"我犯过错并制度性修复"的最强证明——评委要的就是这个】

### 下钻三：天花板冤案 + 尸检（全场记忆点，放慢）
"GitHub 高星 systematic-debugging，分诊 0/6 零信号——但 6 题双臂全满分。**'零增益'和'池子测不出'是两种东西。** → 换带头题（A0∈[0.3,0.7]）再上：裸考 4/4 满分，读了文档均分 0.42——**它不是没用，是有害**。
尸检那个 0 分 run 的 trace：agent 严格走完它教的四阶段，写了篇漂亮的《根因分析》，自信宣布 **'All pass. Fixed.'**——隐藏测试 **0/3**。流程给了它'我验证过了'的底气，没给它'验证得对不对'的能力。"
【此段是全场情绪最高点；评委记住这个故事=记住你】

## 第 3 段 · 从判分到开处方（10:00–12:00）【题目核心闭环】

"题目要求的比评测多一步：**定位失效、有依据地改、再验证**。
- 弊端定位：把 Skill 拆成独立规则，结合判定数据和 trace 证据按弊端排序。机器归因榜首 = `complete-phases-in-order` + `no-fix-without-root-cause`——**和我手工尸检挖出的死因完全一致**（机器和人互相印证）；
- 改进版：砍仪式留干货，8.8K 压到 3.7K，一键送回原流水线同池对照；
- 纪律：辅助 LLM 的结论全部带 κ 水印——**LLM 可以找证据，不能当法官；法官要考资格证（κ≥0.7）**。我的 v1 归因器 κ=0.152，被我自己拦在门外。"

## 第 4 段 · 结果与主动暴露（12:00–13:30）【反思升华=加分项】

"量化结果：三族独立复现，安慰剂校正后 Δ+0.36~+0.68；51 run 沙箱零越界审计；外部文献四方互证（SkillsBench 39/49 零增益、WebDev 平均有害、MT-Bench 判官偏差、官方渐进披露）。
主动暴露五条边界：①单模型单语言单任务域；②归因器 fresh κ 未复标——而且我承认回归用的 20 卡就是它被设计来修的那批，'用考题改错题本'；③自主触发臂没在有效池测过；④池对当前模型已 92% 天花板；⑤成本是 token 不是钱。**评测别人的体系，得先经得起被评测。**"

## 第 5 段 · 收尾（13:30–14:00）

"这个体系回答的不是'Skill 有没有用'，而是'**在什么边界内有用、代价是什么、哪里失效、怎么改**'——它对自己的效度，用同样的标准审判。"

## Q&A 应答纪律 + 十刀

**应答结构（每题都走这四步）**：复述问题（确认理解+争取 3 秒）→ 先给结论 → 分层展开（机制→依据→数据）→ 开放结尾（"这块如果要加深，我的下一步是 X"）。
**纪律**：不说"文档里写了"；不辩解，先承认合理部分再给数据；答不上来就说"这个我没测过，按体系设计应该这样验证……"。

十刀（按被问概率排序，每刀背熟第一句）：
1. **"和 SkillsBench 比增量是什么？"** → "他们测有没有增益，我测增益的边界条件——而且有他们没有的安慰剂臂。"
2. **"n=5/族也叫统计？"** → "单族 n=5 是 pilot 规格，结论靠三族独立同向+预登记五条件，不靠单点 p 值。"
3. **"虚构任务是应试教育。"** → "它是测量仪器不是评测对象——证明因果链用的；真实 issue 挖掘池稀释合成偏差。"
4. **"你是不是故意做难/做易任务？"** → "Pilot Gate 预登记：A0>0.6 算任务失败不是 Skill 有效——我先把做难充数的路给自己焊死了。"
5. **"LLM 归因不就是幻觉？"** → "定量判分零 LLM；归因只在定性层带 κ 水印；机器归因 vs 手工尸检一致性当场可验。"
6. **"二手渠道结论能信？"** → "渠道健康强制披露+熔断+二分——别人把基建噪声吃进结论，我把它摆上台面。"
7. **"演示都是失败的 Skill，题目是不是设计成让 Skill 失败？"** → "三族正收益 +0.36~+0.68 同一池同一判分——它只认知识缺口，不认立场。"
8. **"模型一升级结论就废了吧？"** → "这正是元结论：知识缺口是移动的靶子——所以池健康监控是一等功能，模型升级是体系的输入不是威胁。"
9. **"2400 个 run 多少钱？"** → "DIS 免费额度+漏斗设计，80% 的 Skill 12 个 run 结案，渠道熔断防烧。"
10. **"再给你三周做什么？"** → "池换血（真实挖掘+更难形态）、fresh κ 复标、codex 跨厂商、A1-auto 有效池实测——backlog 顺序我背得出。"
